# 🔥 Fire Fighting Robot using Sound Waves

## 📖 Overview
This project is a Fire Fighting Robot that detects flames using a flame sensor and responds using a sound-wave-based suppression mechanism. The robot can also avoid obstacles autonomously using an ultrasonic sensor.

## 🚀 Features
- Flame Detection
- Obstacle Avoidance
- Autonomous Navigation
- Sound Wave Activation
- Arduino-Based Control System

## 🛠 Components Used
- Arduino UNO
- Flame Sensor
- HC-SR04 Ultrasonic Sensor
- L298N Motor Driver
- DC Motors
- Chassis
- PAM8403 Audio Amplifier
- Speaker/Subwoofer
- Battery Pack
- Jumper Wires

## ⚙️ Working Principle
1. Flame sensor continuously monitors for fire.
2. Ultrasonic sensor detects obstacles.
3. Robot moves autonomously.
4. Upon fire detection:
   - Robot stops.
   - Speaker generates low-frequency sound waves.
5. Sound waves demonstrate fire suppression principles.
